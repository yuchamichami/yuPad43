# 他のファームウェアへの組込み

日本語 | [English](integration.en.md)

RMK・QMK・独自ファームでは、I²C/GPIO/待機処理と、ホストへ送るマウス・スクロール処理を用意します。パッド自身がUSB HIDを直接出力する構成ではありません。

[yuPad43-profile.json](../data/yuPad43-profile.json) に初期化ブロック・RX/TXマップ・設定上書きを収録しました。[register-writes.csv](../data/register-writes.csv) は基礎ブロックのアドレス別一覧です。CSVだけでは上書き、リセット、校正、通信制御が不足します。

| 基準値 | 設定 |
| --- | --- |
| I²Cアドレス | 0x56（7bit表記） |
| 製品番号 | 0x1000から読み、0x09BCを確認 |
| I²C速度 | 100 kHz（実機確認に使用した設定） |
| アドレス・16bit値 | いずれもLittle-endian |
| RX / TX | 10 / 9。マップはJSONを使用 |
| 座標解像度設定 | X=1300、Y=1192。実測の端到達範囲やDPIを意味しません |
| ATI目標 / タッチ閾値 | 400 / 開始30・解除26 |
| Finger Split Factor | 0（隣接したタッチ領域の分割を無効化） |
| ALP / SW\_IN | 無効。TX45を電極に使用 |

### 通信の約束

RDYが物理Lowになった通信窓でアクセスします。読み出しはレジスタアドレス2バイトを送った後、Repeated STARTで読み、最後にSTOPを送ります。例：0x1014を読むアドレスバイトは `14 10` です。GPIOライブラリの「active-low論理値」と実際のLowを取り違えないでください。

STOPで通信窓を閉じる設定です。STOP後に続けて別レジスタへアクセスする場合は、新しい通信窓を待ちます。設定書込みを分割する場合も同様です。ドライバは最大30バイト単位で書き込みます。無応答や時間切れのデータを正常フレームとして扱わないでください。

### 起動処理の順番

1. 電源とRDYを確認し、製品番号を読みます。
2. リセット処理とShow Resetの確認を行い、System ControlのAck Reset（bit7）で通知を解除します。
3. JSONのbase\_write\_blocksを順番に書き、その後post\_write\_overridesを反映します。rotationの処理は他のビットを保持したread-modify-writeです。
4. TP Re-ATI（0x11BCのbit5）を要求します。初期値0からならデータは `20 00` です。稼働中は他ビットを保持します。
5. ATI中は通信可能になるまで待ち、期限内にRDYと完了状態を確認します。完了後はInfo FlagsのATI error（bit3）を別に確認します。
6. 通常フレームを読み、指の検出と移動をホストの入力イベントへ変換します。

ATI完了とATI品質の合格は別です。ATI errorは補正値の上下限への到達や、完了直後にCountが再校正範囲外だったことを示します。断線箇所の番号ではありません。ユーザー向けファームは、ATI完了後に品質警告があっても有効な入力を処理します。警告を理由に起動停止や再校正の繰り返しを行わず、通信失敗・設定書込み失敗・ATI未完了は区別してください。警告を無視しても故障した電極が回復するわけではありません。動作中のShow Resetに対する設定再適用など、ホスト側の復旧処理も必要です。

スクロール専用化なら検出済みの移動量をホイールへ積算し、少量の移動を整数丸めで捨てないよう残量を保持します。タップや2本指ジェスチャの割当て・有効化はホスト側の実装で決めます。

## 読み取れるデータ

通常例は0x1014から28バイトを一括で読みます。これはyuPad43用ドライバが使用する範囲です。[decode\_frame.py](../data/decode_frame.py) はI²Cから取得済みの28バイトを解釈する独立した例です。I²C通信やカーソル出力は含みません。

| アドレス | 形式 | 内容 |
| --- | --- | --- |
| 0x1014 / 0x1016 | int16 / int16 | 相対X / Y移動量 |
| 0x101C / 0x101E | uint16 / uint16 | 1本指 / 2本指ジェスチャのフラグ |
| 0x1020 | uint16 | Info Flags：bit3 ATI error、bit7 Show Reset |
| 0x1022 | uint16 | Trackpad Flags：bit0〜3 指数、bit8/9 指1/2のconfidence |
| 0x1024 / 0x1026 | uint16 / uint16 | 指1 X / Y |
| 0x1028 / 0x102A | uint16 / uint16 | 指1の信号強度 / 面積 |
| 0x102C / 0x102E | uint16 / uint16 | 指2 X / Y |

指が離れたフレームの座標を新しいタッチとして使用しないでください。指の数とconfidenceを併せて扱い、移動量は符号付きで読みます。信号強度は押圧のニュートン値ではありません。座標の上下左右は装着方向に応じて反転・入替えし、実物を右・下へなぞって確認します。

通常のカーソルやスクロールには電極ごとの値は不要です。検査用にはCount・Reference・Deltaの10×9マトリクスを別途読み出せますが、通常フレームとは別レジスタです。取得頻度が操作遅延へ影響するため、常用ファームと検査モードを分けます。
