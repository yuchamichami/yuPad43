# ZMKキーボードへの組み込み用プロンプト

既存のZMKキーボードへyuPad43を追加するときに使える依頼文です。下のブロックをコピーし、対象リポジトリと分かっている接続情報を記入してください。GPIOが分からない場合は、回路図や端子表を添えてください。

```text
既存のZMKキーボードにyuPad43を組み込みたいです。
まず接続図と変更する設定ファイルをまとめ、その後、実装とビルドまで進めてください。

- yuPad43の接続先：単体／左／右
- ホストへの接続：USB／BLE
- 回路図・コネクタの端子表：
- 接続予定GPIO：SDA＝、SCL＝、RDY＝、RST＝未使用またはGPIO
- パッドの取り付け方向：
- 希望する操作：1本指でカーソル、2本指で縦横スクロール

【接続の前提】
yuPad43はIQS9151を使うI²Cデバイスです。ホスト側がUSB/BLEのマウス入力を生成します。
基板の部品面を見て、ケーブル出口を下にしたときのはんだ端子番号は以下です。
1：RDY、2：RST/MCLR、3：GND、4：3V3、5：SCL、6：SDA。

電源は3.3 V、I²Cの7ビットアドレスは0x56、初期のバス速度は100 kHzです。
RDYはactive-lowです。RST/MCLRもactive-lowで、未使用なら開放します。
基板上でSCL・SDA・RDYは4.7 kΩ、MCLRは10 kΩで3.3 Vへプルアップされています。
FPCのType A/Bという名称だけで判断せず、両端の接点面と信号の対応を確認してください。
TPS43と外形・端子配列は互換ですが、使用するのはyuPad43用IQS9151ドライバです。

【作業手順】
1. 対象リポジトリのAGENTS.md、west.yml、ビルド設定、board/shield、
   overlay、conf、keymap、回路図を読んでください。
   ZMKとドライバのリビジョンを記録し、既存の正常な設定を保存してください。
   不明なGPIOやコネクタの向きは推測せず、資料で確認できない箇所だけ質問してください。

2. yuPad43の各端子からホストのコネクタ端子・MCU GPIOまでを表にし、
   接続図を作ってください。電源、I²C、RDY、RSTの扱いを明示してください。
   キーマトリクス、UART、LED、既存のポインティングデバイスとの競合も確認してください。

3. 既存west manifestへyuPad43ドライバを追加してください。
   製品リポジトリ内のwest.ymlにある固定リビジョンを基準にし、
   対象ZMKとの互換性を確認してください。既存manifestを丸ごと置き換えたり、
   ZMKを無断で更新したりしないでください。

4. 実際のドライバのbindingとKconfigを確認し、I²C・GPIO・センサーノード・
   ポインティング入力に必要な設定を追加してください。
   XIAOのGPIO番号、キー入力定義、USB専用設定は移植先へそのままコピーしないでください。
   RSTは使用するドライバが対応する方法で扱い、存在しないreset-gpios設定を作らないでください。

5. 同じセンサーを複数のinput-listenerへ二重登録しないでください。
   分割構成では、パッドを接続した側からcentral、ホストまでの入力経路を確認し、
   対象ZMKのバージョンに合う転送設定を行ってください。
   既存のキー入力、USB/BLE、左右通信と他の入力デバイスを維持してください。

6. 最初はyuPad43の電極マッピング・校正目標・感度を設定例どおりに保ち、
   カーソルとスクロールの軸、方向、量をホスト側で合わせてください。
   スクロール量の標準はレベル0です。設定例の変換を基準にし、二重に倍率を掛けないでください。
   座標範囲はファームの設定値であり、基板の性能上限として扱わないでください。
   校正の品質警告だけで入力を停止しない既存の動作を維持してください。
   通信失敗や未完了の初期化を、有効な入力データとして扱わないでください。

7. 必要なビルド対象をビルドし、生成されたDevicetreeと.configで
   バス・GPIO・センサーノード・入力経路を確認してください。
   ビルド結果と実機結果は分けて報告してください。
   実機への書込みは、対象とブートモードを確認してから行ってください。
   ブートローダーや既存のペアリング情報を消去しないでください。

【動作確認】
カバーを固定し、触れずに起動してから次を確認してください。
- 再起動後も使用できる。
- 軽く触れたときからカーソルが動き、中央と端の少し内側を連続してなぞれる。
- 指を離すと入力が止まり、勝手に動かない。
- 2本指で縦横スクロールでき、方向と速さが意図どおりである。
- キー入力とパッドを同時に使える。
- 使用するUSB/BLE接続で復帰・再接続後も操作できる。

【成果物】
- 実際のGPIOとケーブルの向きが分かる接続図・ピン対応表
- 対象リポジトリへ適用した設定と変更点
- 使用したZMK／ドライバのリビジョン、ビルドコマンド、ファームの保存先
- 実施した確認の結果と元の版へ戻す手順
```
